# Schemas

Machine-readable schemas for specification, authority, SpecIR, semantic-review,
and bounded research artifacts live here.

Accepted RFCs define semantic ownership; a schema file does not silently widen
an RFC's claims.

The lifecycle files:

- `lifecycle-trust-input-v0.1.schema.json`
- `lifecycle-trust-result-v0.1.schema.json`

are **bounded experiment contracts for issue #62**. They make the first
payment-retry lifecycle POC reviewable and machine-readable, but they do not
freeze a universal RFC 0012 storage model.
